Midnight Club 3 — disc import test

Pick your Xbox disc image (.iso: plain XISO or a Redump dump). It parses XDVDFS, streams every file into OPFS under /mc3/game/, writes the manifest, and checks default.xbe is the USA edition. Then it re-hashes three files from OPFS and compares to the Node reference hashes, so you can see the write was byte-exact.
